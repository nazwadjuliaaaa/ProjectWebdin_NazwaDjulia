MODUL 3
Penguatan CRUD, Autentikasi, Role Authorization, dan Manajemen User
Backend Express.js TypeScript + MySQL2 dan Frontend Next.js
Pertemuan 12-15



Deskripsi singkat
Modul ini melanjutkan CRUD dasar Express.js dan frontend Next.js. Fokus utama modul adalah membuat aplikasi lebih realistis: relasi tabel mahasiswa-prodi, upload foto, search/filter/pagination, autentikasi JWT, role authorization, CRUD user, dan reset password.
KomponenTeknologi yang digunakanBackendExpress.js, TypeScript, MySQL2, Multer, bcrypt, jsonwebtoken, NodemailerFrontendNext.js, TypeScript, fetch, FormData, localStorage untuk latihan awalDatabaseMySQL/MariaDBStudi kasusSistem Data Mahasiswa, Prodi, dan User

Peta Kompetensi Modul 3
Setelah menyelesaikan modul ini, mahasiswa diharapkan mampu:
* Membuat relasi tabel sederhana antara mahasiswa dan prodi menggunakan foreign key.
* Membuat endpoint CRUD mahasiswa yang mendukung upload foto, search, filter, dan pagination.
* Menghubungkan frontend Next.js dengan backend Express.js menggunakan fetch, URLSearchParams, FormData, dan Authorization header.
* Membuat fitur register dan login menggunakan hash password dan JWT.
* Membuat protected route agar endpoint tertentu hanya dapat diakses oleh user yang sudah login.
* Membuat role authorization untuk membedakan akses admin, operator, dan viewer.
* Membuat CRUD daftar user dan fitur reset password, termasuk opsi pengiriman email menggunakan SMTP Gmail untuk kebutuhan praktik.

Prasyarat
* Mahasiswa sudah dapat menjalankan backend Express.js TypeScript.
* Mahasiswa sudah memahami endpoint CRUD dasar dengan MySQL2.
* Mahasiswa sudah dapat menjalankan frontend Next.js dan memanggil REST API backend.
* Database MySQL/MariaDB sudah aktif dan bisa diakses dari backend.
